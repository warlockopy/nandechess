# NandeChess

Una aplicación de ajedrez en tiempo real construida con React y Node.js.

## Estructura del Proyecto

- `client/`: Frontend en React
- `server/`: Backend en Node.js

## Requisitos

- Node.js
- npm

## Instalación

### Cliente (Frontend)

```bash
cd client
npm install
npm run dev
```

### Servidor (Backend)

```bash
cd server
npm install
node index.js
```

## Tecnologías Utilizadas

- Frontend:
  - React
  - Vite
  - Socket.IO Client

- Backend:
  - Node.js
  - Express
  - Socket.IO
  - CORS

## Desarrollo

El frontend corre en `http://localhost:5173` y el backend en `http://localhost:3000`.
